# Git
*Norma del owner, 2026-10-01 (D5, confirmada en D37).*

- Conventional Commits en inglés con scope: `feat(scanner): ...`, `fix(mhl): ...`, `docs(rules): ...`, `chore(release): vX.Y.Z`, `test(...)`, `ci(...)`. Cuerpo en prosa explicando el porqué, citando `Dn`, `Hn` o `#issue`.
- Un commit por tarea. El repo nunca se deja roto: `make ci` verde antes de cada commit.
- SemVer. Hito 0 = `v0.0.1`, hito N = `v0.N.0`. Tags anotados `vX.Y.Z`; nunca se reescribe un tag publicado.
- Ramas: `feat/<issue#>-slug`, `fix/...`, `docs/...`. PR con `Closes #N`. Las ramas integradas se borran sin preguntar (`gh pr merge --delete-branch`). Nunca se commitea directo a `main` (norma `rama-main-protegida.md`, D55; hasta el MVP se permitía).
- Sin trailers de atribución (`Co-Authored-By`, `Signed-off-by`): `includeCoAuthoredBy: false` en `.claude/settings.json`. Confirmado para este repo público (D37). Tampoco enlaces de sesión ni pies «Generated by…» en commits, tags, PR ni issues: lo comprueban `make attribution-check` (en `make ci`) y un hook `PreToolUse` (D64).
- Nunca `git push --force` a `main`.

**Por qué:** historial legible por humanos y por `git log --grep`, y releases reproducibles desde el tag.
